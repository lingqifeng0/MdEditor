# 显示调节与文件重载提示

## 确认的需求

- 文件在别处更新且本地有未保存内容时，显示「文件名」已在别处更新。用新版替换未保存的内容吗？
- “确定”放在提示文字旁，关闭按钮在最右侧。窄窗口里“确定”排到文字下方，关闭按钮保留在右上角。
- 偏好设置的“主题”中提供“全局”和“图片”两组设置，各有亮度、护眼模式和暖色强度。
- 全局亮度作用于编辑器窗口，图片亮度额外作用于 Markdown 和 HTML 图片。界面暖色和图片暖色独立调节。
- 初始亮度为 100%，护眼关闭，暖色强度为 40%。关闭护眼保留上次的强度。设置随应用重启恢复。
- 显示效果使用渲染器样式，保存和导出继续使用原始内容。

## 验收

- 用真实文件监视验证自动重新加载以及有未保存内容时的关闭、确认和布局。
- 在 Electron 中验证两组设置、普通和 HTML 图片以及重启恢复。
- 验证启用显示设置时，大图滚动和浮动目录定位仍可操作。

## 验证结果

- Windows Electron 端到端测试 14 项通过。覆盖真实文件监视、确认与关闭、窄窗口、撤销和源代码模式滚动位置，也覆盖 Markdown 与 HTML 图片的实际渲染颜色、设置搜索、重启恢复、打印样式和大图滚动。
- 桌面单元测试 1748 项通过，36 项按项目配置跳过。各语言键和占位符一致性通过。
- 桌面构建、渲染器类型检查、改动文件 ESLint 和 `git diff --check` 通过。

## Windows v8.40 本地打包

- 成品放在 `MarkText-Toolbar/Windows-v8.40`，包括 EXE 安装包、一个以 `MdEditor/` 为根目录的便携 ZIP 和 SHA-256 校验文件。
- 使用 pnpm 10.33.4 构建 NSIS 安装包。核对程序版本、安装程序的 Windows 文件描述、x64 搜索组件和开源许可。
- 从最终安装包提取程序并解压最终 ZIP。两个程序均通过启动、搜索、保存后重新打开笔记的检查，也分别通过重载提示与显示设置的实际成品测试。
- NSIS 完整性、ZIP CRC、便携包内文件与构建产物的字节一致性，以及本地交付文件的 SHA-256 均已验证。
